# MoodMix
Track your daily mood through an interactive emoji interface and get AI-curated music recommendations based on your emotional patterns. Features:
- Simple drag-drop emoji mood logging
- Beautiful animated mood transitions
- Weekly/monthly emotional insights
- Spotify integration for mood-based playlists
- Social sharing of mood patterns
- Streak tracking for consistent logging

Built with HTML5, CSS3, JavaScript, and the Web Audio API for ambient sounds.
